# 狐隱 KOGAKURE｜網站開發計畫

日期：2026-11-08
位置：D:\kogakure

## 產品原則

1. 手機版優先考慮直接操作：單欄閱讀、明顯按鈕、44px 以上觸控目標，無 hover 才能使用的功能。手機底部採 5 格固定導覽（首頁、人員、值班、點菜、更多），其餘館內介紹／服務內容／預約放在「更多」內，桌面保留頂部導航。
2. 桌面版乾淨完整：在寬螢幕增加內容寬度與字體，不把大量資訊縮到很小字。
3. 暗色環境易讀：正文 >= 17px，桌面約 18px；主要資訊高對比、良好行距與分段。
4. 輕量載入：分頁程式碼拆包、WebP 圖片、縮圖優先、按需載入大圖、不加入大體積動畫套件。
5. 統一設計：午夜藍黑 + 漆金 + 狐火青 + 少量櫻粉／朱紅；御守卡是「人員介紹」的特色，不強套所有頁面。
6. 資料由後台管理：不把常變動的內容寫死在前端檔案。必須有 RLS、驗證、存取權限與狀態切換。
7. 所有正式提交的圖片為最佳化版本，原圖留在本地素材資料夾而不公開。

| 05 值班排班 | 週視圖、當日值班、值勤時間 | 排班 CRUD、員工與時段的關聯、重複排班提示 |

## 社群連結與個人特效

每位員工後台欄位 `effect` 可選：
- `foxfire` 狐火青球（預設）
- `sakura` 櫻花花瓣
- `starlight` 星點
- `gold` 金色微光
- `none` 無特效

另以 `themeColor` 個別設定粒子或標題點綴色。社群為可增減的 `[{id,label,url}]` 陣列，僅接受 http(s) 網址，詳細頁直接顯示，不在名帖中加入「立即預約」。
